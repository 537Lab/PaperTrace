# GOV-02/COST-01: real evaluation execution and immutable artifact transport

Status: proposed for independent review; no live dispatch or authorization. Related Issue #44.

## Verified blocker
The existing v3 verifier requires `report.provenance.artifact_id` inside the report that is uploaded as an immutable GitHub artifact. The ID is assigned by GitHub only after the upload. Reuploading creates a different ID. The PR body and the server artifact metadata already bind the real ID, run, head and ZIP digest. Require repository and run_id inside the report; allow legacy v3 artifact_id only when it equals the server ID. Never allow wrong, null, or invented IDs. Keep server run/head/name/expiry/digest, approved evaluator/workflow blobs, raw report hash, independent pre/post review, dataset, request, runtime, budget, and all thresholds intact. Do not alter previous approved tests. This is a protected gate/schema change: separate approved test proposal and independent safety review of implementation before adoption. No evaluator can certify itself.
