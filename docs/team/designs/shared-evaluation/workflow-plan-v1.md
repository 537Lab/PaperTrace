Both fixed CLI steps receive the matching repository vars `PAPERTRACE_LLM_INPUT_COST_PER_MILLION` and `PAPERTRACE_LLM_OUTPUT_COST_PER_MILLION`. Collect revalidates against its own environment before provider transport.

A review can authorize at most one fresh dispatch, including after success, failure or cancellation. Visible concurrent runs carrying the same review must never both pass. Synthetic snapshots cover visible conflicts. Implementation review must verify that simultaneous dispatches cannot both pass before their records become mutually visible.

## PR #82 rerun and tokenizer review response

- All three CLI stages receive `PAPERTRACE_RUN_ATTEMPT` from `${{ github.run_attempt }}`. Preflight and collect require the server and environment to agree that this is attempt 1. Reject a same-workflow, same-head prior dispatch whose server title lacks an authorization marker. Collect checks the current run's artifact listing before provider entry and refuses an existing `papertrace-semantic-raw`, including an expired artifact record. The artifact check detects recorded prior collection. Simultaneous collectors before an artifact is recorded still require an atomic claim or equivalent execution control.
- ADR-001 requires the approved, locked, model-specific tokenizer to count the final system and user messages with framing immediately before dispatch. Accept at most 12,000 input tokens. Missing tokenizer support, loader or counting failures, and counts that are non-integer or nonpositive must stop collection before any provider call. Byte and character estimates cannot substitute for the tokenizer. Offline tests inject deterministic counters or replace only the `tiktoken` dependency in `sys.modules`. The latter exercise the real loader and collect on missing imports, failed encoding loads, and successful encoding with message framing. Neither route downloads BPE files or enters the provider.
- The proposed stage boundary is `collect(ctx, client, *, pr_number, run_id, authorization_review_id, system_prompt_path="prompts/answer-system-v1.0.txt", transport=...)`. An explicit approved path is read at the authorized head. The synthetic fixture supplies `prompts/system.txt`. A missing prompt path fails closed without trying another file. The run artifact list uses `GET /repos/537Lab/PaperTrace/actions/runs/{run_id}/artifacts?per_page=100`. The loader `load_approved_token_counter(*, provider: str, model: str)` uses the authorized provider and model and returns a counter over ordered `(role, content)` pairs, the same message representation passed to the transport. `count_final_request_tokens(messages, *, counter=...)` exposes the exact framed count for checks. Collect repeats the tariff checks against its own environment and re-fetches the run and dispatch history. A mismatched HEAD, a consumed review or an untagged prior dispatch must stop collection before any provider call. An untagged title includes a missing field, null, empty text, whitespace or a nonempty title without the authorization marker.
